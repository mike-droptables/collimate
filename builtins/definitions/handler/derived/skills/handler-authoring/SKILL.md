# File handlers

Author guidance and example folders with explicit expected verdicts and feedback. Omit `derived/` when authoring a handler package. Add it to Capabilities, then Build it from its card (it opens a work stack); add the result back, then review and accept the build on the card.

Read the canonical guides in `references/`. Write supporting files first and the definition last, then call `validate`. A work-cell definition is inert until the user adds it with Add to Capabilities.
