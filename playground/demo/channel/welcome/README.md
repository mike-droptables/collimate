# Welcome to the Collimate playground

This is the real Collimate app running entirely in your browser — the same
interface, cells, runs and version history you get on your own machine.
Nothing is sent anywhere and nothing is saved: reload the page and the demo
starts over.

What is real: the app itself, the runner picker, the live terminal and chat
renderers, and the version history every run leaves behind.

What is fake: the generators. Each of the three demo runners plays a script
with realistic pacing — a shell session, an assistant conversation and a
file-editing agent — so you can see how a run looks and feels without any
model, container or network behind it.

Try it: pick a cell (the **Sample notes** cell suits *Modify files*), open the
runner picker, choose a demo runner and start it. Press **Stop** to end a run
early and step through the versions it left.
